# Workflows

Workflows is an AI-native workflow operating system. It learns reusable workflows from human and agent behavior, versions them, and orchestrates AI and human workers across pluggable execution environments.

The MVP is browser-first. Software development is the first dogfood workflow; it is not the product domain.

## Repository authority

This repository is the durable source of truth for architecture, implementation sequencing, work authorization, development state, evidence, and engineering operating rules.
