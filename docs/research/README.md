# Research Record

This directory stores research that materially influences architecture or implementation.

## Required record shape

Each research record should identify:

- question
- date reviewed
- sources
- relevant evidence
- decision influenced
- confidence
- unresolved disagreement

## Initial research families

- browser agents: WebArena, WebVoyager, Mind2Web, WebLINX, BrowserGym/WorkArena, OSWorld
- workflow learning: Agent Workflow Memory, Voyager, Reflexion and related trajectory/skill-learning work
- agent security: AgentDojo and prompt-injection/tool-use research
- agent memory: LongMemEval, Generative Agents, procedural/skill memory systems
- implementation references: OpenClaw, Hermes Agent, Browser Use, Stagehand
- infrastructure: Vercel, Neon, Upstash, Cloudflare R2/Workers/Durable Objects, Apify, remote-browser providers

Research is evidence for design; it is not authority over the frozen architecture.
