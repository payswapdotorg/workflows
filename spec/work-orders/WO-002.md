# WO-002 — Architecture and Security Constitution

**Status:** VERIFIED
**Architecture Version:** 1.0
**Assigned Role:** Architect
**Risk:** HIGH

## Objective
Freeze the universal workflow architecture and trust/security invariants.

## Required artifacts
- `spec/architecture/ARCHITECTURE.md`
- `spec/architecture/ARCHITECTURE-LOCK.md`
- `spec/architecture/SECURITY-MODEL.md`
- `spec/architecture/AGENT-ORCHESTRATION.md`

## Acceptance criteria
- Teaching has DEMONSTRATE, INSTRUCT, and HYBRID modes.
- Workflow definitions and versions are distinct from executions.
- Roles and harnesses are first-class.
- Browser is an execution substrate, not workflow authority.
- LLMs/agents are replaceable participants.
- Provenance and prompt-injection boundaries are explicit.
- Human takeover is first-class.
- Architecture changes require a new immutable architecture version.
