# WO-003 — Agent Operating and Review Protocol

**Status:** VERIFIED
**Architecture Version:** 1.0
**Assigned Role:** Tech Lead
**Risk:** STANDARD

## Objective
Define autonomous specialist orchestration, parallelization, handoffs, exact-head verification, and failure handling.

## Acceptance criteria
- Normal concurrent implementation limit is three specialists.
- Work Orders declare dependencies and change surfaces.
- Sibling implementations may not depend on unmerged sibling branches.
- Exact-head verification is required before Architect review.
- Changed PR heads invalidate prior exact-head evidence.
- Completion requires merge plus evidence reconciliation.
