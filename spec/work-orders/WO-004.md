# WO-004 — Work Order Contract

**Status:** VERIFIED
**Architecture Version:** 1.0
**Assigned Role:** Architect
**Risk:** STANDARD

## Objective
Establish the canonical contract for bounded implementation work.

## Acceptance criteria
- Every Work Order has objective, dependencies, change surfaces, forbidden surfaces, acceptance criteria, verification and evidence requirements.
- Work Order lifecycle states are explicit.
- Completion is merge plus reconciliation, not agent claim.
- The dependency graph can be used to compute eligibility.
