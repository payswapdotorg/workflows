# WO-005 — Conformance and CI Foundation

**Status:** READY
**Architecture Version:** 1.0
**Assigned Role:** DevOps/Evaluation Specialist
**Risk:** STANDARD

## Objective
Create automated checks that prevent architecture/governance drift from entering main.

## Acceptance criteria
- CI runs on pull requests and main.
- Architecture lock/invariant files are checked for required presence and syntax.
- Dependency graph JSON is schema-valid.
- Work Order records have required fields.
- Secrets/config files are excluded from source control.
- Unit/type/lint test commands are defined once the application skeleton exists.

## Change surface
`.github/**`, `tests/conformance/**`, governance validation scripts.

## Forbidden
Do not modify frozen architecture meaning or application semantics.
